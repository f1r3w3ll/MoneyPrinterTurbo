QUICK START:

1. Configurar API Keys:
   curl -X POST http://127.0.0.1:8081/api/v1/llm-config \
     -H "Content-Type: application/json" \
     -d '{"configs":[{"provider":"openai","api_key":"sk-...","enabled":true}]}'

2. Gerar Roteiro:
   curl -X POST http://127.0.0.1:8081/api/v1/generate-script \
     -H "Content-Type: application/json" \
     -d '{"topic":"História da IA","duration_minutes":20,"language":"pt-BR","llm_provider":"openai"}'

3. Criar Vídeo:
   curl -X POST http://127.0.0.1:8081/api/v1/longform-videos \
     -H "Content-Type: application/json" \
     -d '{"structured_script":{...},"image_provider":"dalle"}'

TROUBLESHOOTING:

  Erro: "LLM provider not configured"
  → Configurar API key via POST /llm-config

  Erro: "at least 5 scenes"
  → Adicionar mais cenas ao script (mínimo 5)

  Tarefa travada:
  → curl http://localhost:8081/api/v1/checkpoint-status/{task_id}
  → curl -X POST http://localhost:8081/api/v1/resume-task/{task_id}

  Memória insuficiente:
  → Reduzir chunk_size no config.toml
